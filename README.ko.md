# 온라인 서점 데이터베이스 — 데이터베이스 시스템 수업 프로젝트

> 북경대학교 데이터베이스 시스템 수업 · 2021~2022 · 5인 팀 프로젝트 · PHP + MySQL
>
> ⚠️ **과거 수업 과제를 재현한 코드로, 인터넷에 배포할 수준의 보안성을 갖춘 서비스가 아닙니다. 로컬 개발용으로만 사용하세요.**

![원래 프로젝트의 메인 화면](docs/screenshots/01-home.png)

## 프로젝트 개요

PHP 웹 애플리케이션과 MySQL 관계형 데이터베이스를 연동한 온라인 서점 프로토타입입니다. 도서 등록·수정·삭제, 검색, 회원 관리, 장바구니, 주문 기록, 평점·리뷰 등 관계형 데이터베이스 중심의 기본 업무 흐름을 구현한 수업 결과물입니다.

## 구현된 기능 (제출 코드 기준)

- **도서:** 도서 목록·상세정보·검색(제목, 저자, 출판사)
- **관리자:** 도서 추가·수정·삭제, 주문 내역 확인
- **회원:** 회원가입, 로그인 및 세션
- **장바구니:** 상품 추가, 수량 변경, 삭제
- **주문:** 장바구니 정보를 `orders` 테이블에 기록하는 데모 흐름 (실제 결제 연동 없음)
- **평가:** 별점과 리뷰 등록·수정, 평균 별점 조회

> 기능 존재 여부는 코드를 기준으로 확인했습니다. 준비 과정에서 웹 서버와 MySQL을 연동한 전체 실행 테스트까지 완료한 것은 아닙니다.

## 기술 스택 및 데이터베이스

PHP, MySQLi, MySQL 5.7(원본), Bootstrap, HTML/CSS, JavaScript. 실제 SQL에 존재하는 테이블은 `book`, `user`, `cart`, `orders`, `rate`의 **5개**입니다. 보고서에 등장하는 `few_author`, `bA` 테이블은 실제 덤프에는 없으므로 구현했다고 주장하지 않습니다. [스키마 설명](docs/SCHEMA.md)

## 로컬 실행 방법

1. WAMP 같은 PHP+MySQL 개발 환경을 설치합니다. 원본 환경은 PHP 7.3 / MySQL 5.7이고 최신 버전 호환성은 검증되지 않았습니다.
2. phpMyAdmin에서 `bookstore` 데이터베이스를 만듭니다.
3. [`database/bookstore.sql`](database/bookstore.sql)을 import합니다. 공개용 SQL은 실제 계정이나 주문 정보가 없는 가상의 도서 샘플입니다.
4. 프로젝트 폴더를 `wamp64/www/online-bookstore-database`로 복사합니다.
5. 데이터베이스 접속은 `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` 환경변수로 설정할 수 있습니다. 기본값(root/빈 비밀번호)은 **격리된 로컬 환경 전용**입니다.
6. 브라우저에서 `http://localhost/online-bookstore-database/index.php`를 엽니다.
7. 회원가입으로 테스트 계정을 만듭니다. 관리자 기능이 필요하면 **로컬 테스트 DB에서만** `UPDATE user SET permission='root' WHERE userid='YOUR_TEST_ID';`를 실행합니다.

## 공개용으로 정리하면서 바뀐 것

원본 샘플 계정/평문 비밀번호/기존 사용자 정보/상업 도서 설명/표지 이미지를 제외했습니다. 대신 허구의 도서 샘플 데이터를 넣고, DB 설정을 분리하고, 가입·로그인에 prepared statements 및 비밀번호 해싱을 적용했습니다. 또한 실제 결제와 관계없는 카드번호 입력 화면을 제거했습니다. **이 변경 사항을 당시 팀 프로젝트의 구현 성과라고 주장하면 안 됩니다.**
